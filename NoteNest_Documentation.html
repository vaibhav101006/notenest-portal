📑 Executive Summary & Architecture

NoteNest is built from the ground up strictly according to pure web standards. It requires zero backend servers, zero build steps, and zero third-party UI toolkits. Every component, transition, responsive drawer, modal dialog, and data synchronization is handcrafted using native web APIs.

🎓 Section 4: College Viva-Voce Quick Reference Guide

Essential questions and model answers to help explain this project during technical evaluations, lab exams, and viva presentations.

Q1: How does NoteNest achieve data persistence without a backend or MySQL database?
Answer: NoteNest utilizes the HTML5 localStorage Web Storage API. JSON-serialized datasets (notenest_notes, notenest_user, notenest_bookmarks, notenest_recent) are stored locally in the user's browser client. Any note uploads, bookmark toggles, profile edits, or theme switches are serialized with JSON.stringify() and retrieved with JSON.parse() upon page load.
Q2: How does the application filter notes across multiple criteria simultaneously?
Answer: The filtering engine in explore.js uses JavaScript's functional array pipeline (Array.prototype.filter() and Array.prototype.sort()). It evaluates multiple predicates sequentially: search query regex/string matching against title, subject, uploader, and tags; strict equality checks for Department, Semester, Note Type, and Subject; and numerical comparison for Minimum Rating.
Q3: How is responsive layout achieved across mobile, tablet, and desktop without Bootstrap or Tailwind?
Answer: Responsiveness is built using pure CSS3 Flexbox, CSS Grid with dynamic repeat formulas (grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))), and CSS Media Queries at 1024px, 768px, and 480px. On smaller screens, the desktop filter sidebar automatically transforms into an off-canvas slide-out drawer triggered by JavaScript.
Q4: How do different pages communicate and share updated state?
Answer: All pages include the shared common.js module before their specific script. common.js manages the global NoteNest object and exports reactive hooks (window.onBookmarksUpdate, window.onNotesUpdate, window.onUserUpdate). When an action occurs on any page or modal, these hooks trigger automatic component re-rendering.
Q5: How is simulated file download implemented in pure JavaScript?
Answer: When a user clicks "Download Note", downloadNote() creates a temporary text Blob in memory using new Blob([content], { type: 'text/plain' }). It then creates a virtual <a> element, assigns URL.createObjectURL(blob) to its href, sets the download attribute to the note's filename, and programmatically triggers a.click() to initiate the browser download.
